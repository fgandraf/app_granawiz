================================
Continue a internacionalização (i18n) dos arquivos Kotlin listados abaixo.
O projeto é o GranaWiz (Kotlin Compose Desktop, pt-BR). Os recursos de string
ficam em:
  - app/src/main/composeResources/values/strings.xml         (inglês — padrão)
  - app/src/main/composeResources/values-pt-rBR/strings.xml  (português)

Regras:
1. Para cada arquivo da lista, localize as strings hardcoded visíveis ao usuário.
2. Se a chave já existir no strings.xml, use-a diretamente.
3. Se a chave não existir, adicione-a nos DOIS arquivos XML antes de usar.
4. Substitua a string hardcoded por stringResource(Res.string.<chave>).
5. Adicione os imports necessários (Res, * e stringResource) se ainda não estiverem.
6. Strings em funções NÃO-composable (ex: buildRecurrenceSummary em
   RecurrencePicker.kt) não podem usar stringResource — avalie refatorar para
   receber as strings como parâmetros vindos do contexto composable chamador.
7. Após cada lote de 5 arquivos, pare e pergunte se deve continuar.
8. Ao concluir cada arquivo, remova-o desta lista.

Padrão de import usado no projeto:
  import com.felipegandra.generated.resources.Res
  import com.felipegandra.generated.resources.*
  import org.jetbrains.compose.resources.stringResource
